# NovaFlow 账号工作区

[English](guide.md) | 中文

## 变更

NovaFlow 为各站点及用户 ID 分别选择工作区、会话和插件设置。退出登录后，不再显示原账号的侧边栏。新账号默认关闭第三方插件。切换账号会关闭旧工作区并停止其 Host。

## 迁移

1. 升级前保留当前账号的加密登录记录。NovaFlow 会将旧数据绑定到该记录中的身份，已有工作区和会话文件保留原位。
2. 如果系统凭证存储无法读取，请解锁后重启 NovaFlow。没有登录记录时，旧文件保持未分配，绝不会自动交给后续登录的账号；请保留文件，按需明确执行手工恢复。
3. 登录另一个账号，确认侧边栏是新的，并只启用该账号需要的插件。切回原账号，确认工作区和插件选择已经恢复。
4. 通过 CLI 管理插件前，完全退出桌面端，并明确将 `DSH_HOME` 设为该账号的目录。参见[账号路径和限制](../../../../apps/desktop/novaflow/README.zh.md#account-workspaces)。
